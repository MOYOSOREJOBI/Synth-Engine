      Architecture
      
      
      PulseSynth uses a Rust WASM DSP core running inside an AudioWorklet for real-time synthesis. The worklet communicates with the main thread via postMessage. All DSP runs in the audio thread with zero allocations in the render loop.
      
      
      COOP/COEP
      
      
      For SharedArrayBuffer support, the page requires Cross-Origin-Opener-Policy: same-origin and Cross-Origin-Embedder-Policy: require-corp headers. The Vite dev server provides these. For production, configure your hosting provider.
